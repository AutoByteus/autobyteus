## What's New
- Added `generate_video`, a multimedia tool that creates videos from a prompt plus optional image, audio, and video references.
- Added Autobyteus RPA LLM server-backed video model discovery with support for host-qualified model identifiers.
- Added `gemini-omni-app-rpa` as the default video generation model.

## Improvements
- Documented image, audio, and video generation tools in a new multimedia tools guide.
